# private/output/

Aqui ficam os resultados gerados pelos scripts sobre os teus dados reais (ex: `python3 mal_to_tvtime.py`, que sem argumentos lê de `private/mal/` e escreve aqui `tvtime-series-<hoje>.json` e `tvtime-movies-<hoje>.json`).

Tudo o que aparecer aqui (exceto este README) fica fora do git — ver `.gitignore` na raiz do repo.
