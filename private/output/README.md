# private/output/

## English

The scripts' results on your real data land here (e.g. `python3 mal_to_refract.py`, which with no arguments reads from `private/mal/` and writes `tvtime-series-<today>.json` and `tvtime-movies-<today>.json` here).

Everything that shows up here (except this README) is excluded from git — see `.gitignore` in the repo root.

## Português

Aqui ficam os resultados gerados pelos scripts sobre os teus dados reais (ex: `python3 mal_to_refract.py`, que sem argumentos lê de `private/mal/` e escreve aqui `tvtime-series-<hoje>.json` e `tvtime-movies-<hoje>.json`).

Tudo o que aparecer aqui (exceto este README) fica fora do git — ver `.gitignore` na raiz do repo.
