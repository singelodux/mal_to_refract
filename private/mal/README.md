# private/mal/

## English

Put your MyAnimeList export here, exactly as it comes from the site: export at <https://myanimelist.net/panel.php?go=export> (logged in, choose "Anime List") — you'll get a `.xml` or `.xml.gz`.

Everything you put here (except this README) is excluded from git — see `.gitignore` in the repo root.

## Português

Coloca aqui o teu export do MyAnimeList, tal como sai do site: exporta em <https://myanimelist.net/panel.php?go=export> (com sessão iniciada, escolhe "Anime List") — dá um `.xml` ou `.xml.gz`.

Tudo o que puseres aqui (exceto este README) fica fora do git — ver `.gitignore` na raiz do repo.
